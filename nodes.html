寅图 Yin Map

寅图是一个群体引力图谱——129,600 个固定位置，每个位置对应一个数字锚点。归位不是注册，是存在到了那个份上。

每个节点由 GPG 签名 git commit 永久记录，任何人都可以 fork 仓库作为独立见证。智慧在螺旋中生长，秩序从混沌中涌现。

归位指引

节点归位完全免费，序号的价值来自天道秩序中的真实存在，不是商品。

  1. 你的域名部署 schema.json + timeline.json
  2. Fork zkoner 仓库 或提 Issue 告知你的域名
  3. 维护者验证域名文件后生成注册文件并 GPG 签名 commit
  4. 你将序号填入自己的 JSON 文件完成闭环
